# E-Commerce Web Application (LAMP Stack)

A full-stack e-commerce platform built with PHP and MySQL, providing customer shopping features alongside an administrative management dashboard.

## Features
- **User Authentication:** Secure registration, login, and session management.
- **Product Catalog:** Dynamic product display with category filtering.
- **Shopping Cart & Checkout:** Full CRUD operations for order and cart handling.
- **Admin Panel:** Complete controls for product inventory updates and order management.

## Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** PHP
- **Database:** MySQL
- **Environment:** Apache (LAMP Stack)

## Database Setup
1. Import the database schema from `database.sql` into phpMyAdmin / MySQL.
2. Update the database connection credentials in `config.php`.# ecommerce-php-mysql
